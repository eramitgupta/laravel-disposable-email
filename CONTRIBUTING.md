# Contributing

Thanks for your interest in contributing to **Laravel Disposable Email Address Validator**!

This project is open source, and contributions of all sizes are welcome. Whether you're fixing a bug, improving documentation, adding tests, or suggesting a feature, your help is appreciated.

## How to Contribute

There are several ways to help improve the package:

- **Report a bug:** Found something that isn't working correctly? [Open an issue](https://github.com/eramitgupta/laravel-disposable-email/issues) with details and steps to reproduce it.
- **Suggest a feature:** Have an idea that could make the package more useful? Feel free to share it in an issue.
- **Improve documentation:** Fix unclear explanations, typos, or missing examples.
- **Submit a pull request:** Help improve the code, performance, validation accuracy, or test coverage.

For missing or incorrect disposable email domains, you can also contribute to the [Disposable Email Blocklist](https://github.com/eramitgupta/disposable-email).

## Local Development

To get started:

1. Fork the repository on GitHub.
2. Clone your fork:

   ```bash
   git clone https://github.com/YOUR_USERNAME/laravel-disposable-email.git
   cd laravel-disposable-email
   ```

3. Install the dependencies:

   ```bash
   composer install
   ```

4. Create a separate Laravel application if you want to test the package in a real project.

5. Make your changes and run the relevant tests before submitting a pull request.

## Pull Request Guidelines

Before opening a pull request, please:

- Follow PSR-12 coding standards and the existing project conventions.
- Keep changes focused on a specific issue or improvement.
- Add or update tests when changing functionality.
- Update documentation if your changes affect how the package works.
- Make sure existing tests continue to pass.
- Explain what you changed and why it was necessary.

If your change fixes an existing issue, include the issue number in your pull request description.

## Reporting Bugs

When reporting a bug, try to include:

- The Laravel, PHP, and package versions you're using.
- What you expected to happen.
- What actually happened.
- Steps to reproduce the issue.
- Any relevant error messages or code examples.

The more information you provide, the easier it is to investigate.

## Code of Conduct

Please be respectful and constructive when discussing issues, reviewing code, or contributing changes.

Different ideas and approaches are welcome. The goal is to improve the project together.

## Thank You

Thanks for taking the time to contribute!

Every bug report, suggestion, documentation improvement, and pull request helps make this package better for the Laravel community. ❤️
